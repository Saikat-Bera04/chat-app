# **App Name**: Secret Heartbeat

## Core Features:

- Code-Protected Access: Require a secret code to unlock and use the application.
- Real-Time Chat: Enable real-time chat between you and your girlfriend.
- Message Persistence: Use the app's local storage to save messages.
- Progressive Web App Features: Ensure the app is installable, works offline, and provides a native app-like experience.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to evoke feelings of gentleness and romance.
- Background color: Very light gray (#F5F5F5) for a clean, calming backdrop.
- Accent color: Dusty rose (#D8BFD8) to highlight important UI elements like send buttons and message bubbles.
- Font: 'Literata' serif, for both headings and body text.
- Use heart-themed icons where applicable, in the dusty rose accent color.
- Clean, simple layout with an emphasis on readability. Central chat area with input field at the bottom. Consider using the mobile view as the primary display layout.
- Subtle animations, like message bubbles gently expanding or a heart pulsing on message receive, to add warmth.
